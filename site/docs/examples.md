# Examples

The following OpenCLI Descriptions are maintained in the
[`examples`](https://github.com/spectreconsole/open-cli/tree/main/examples)
folder of the specification repository. Each one was generated by probing the
installed application, from its help output, its manual and, where the
application offers one, a machine-readable description of its commands.

Browse any of them in the [Explorer](/explorer), or download the description
itself.

## .NET SDK

The [.NET SDK](https://learn.microsoft.com/dotnet/core/tools/) command line
interface, generated from .NET SDK `10.0.302`. It covers every SDK command,
including hidden ones, the runtime options used when running an application,
and the bundled tools such as `dotnet format`, `dotnet fsi` and `dotnet watch`.

Most of it comes from `dotnet --cli-schema`, which describes the command tree,
including [recursive](/#option-object) options, option
[arguments](/#argument-object) with an [arity](/#arity-object), and hidden
commands and options.

<Example id="dotnet" />

## Git

[Git](https://git-scm.com) `2.50.1`, generated from `git help -a`, the `-h`
output of every command and subcommand, and the Git manual pages. It shows a
deep command tree: commands such as `git remote` and `git stash` have their
own subcommands, each with their own arguments and options.

<Example id="git" />

## curl

[curl](https://curl.se) `8.7.1`, generated from `curl --help all`, the option
categories and the built-in manual. A single command with a large number of
[grouped](/#option-object) options and a long list of
[exit codes](/#exitcode-object).

<Example id="curl" />

## FFmpeg

[FFmpeg](https://ffmpeg.org) `8.1.2`, generated from `ffmpeg -h full`. It
includes the options of every codec, format and protocol in the build, which
makes it one of the largest command lines around: more than a thousand options
on a single command.

<Example id="ffmpeg" />
